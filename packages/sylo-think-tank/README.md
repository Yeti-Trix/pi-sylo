# @sylo/sylo-think-tank

Multi-model think tank for Sylo. Enable in **Capability manager → Sylo optional packages**, pair with the **think-tank** skill, then ask in chat:

- `Think Tank: should we use DSR 0.95 for backtest gates?`
- `Send this to the think tank: …`

Tools: `sylo_think_tank_run`, `sylo_think_tank_status`, `sylo_think_tank_pick`.
