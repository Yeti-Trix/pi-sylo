# Speech route fallback

Use chat: ask the agent to *"convert this to speech"* and paste your text. The agent calls **`sylo_tts_speak`**.

Enable **sylo-tts** in Capability manager, install Python deps, restart the broker. Default voice: **Leo (Orpheus)** — change in sylo-tts extension config.

Without the route UI, TTS still works entirely from chat.
